# 批量射线拾取

一个能对大量射线做批量求交、并保持最近命中顺序稳定的拾取器。**仅使用
Python 标准库**，无第三方依赖。

## 保留签名

- `Ray(origin, direction)`
- `Triangle(index, a, b, c)`
- `intersect(ray, tri)`
- `pick_all(rays, tris)`

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `raypick/geom.py` | 容差常量 `EPS` 与基础向量运算 |
| `raypick/core.py` | `Ray` / `Triangle` / `Hit`、`intersect`、`pick_all` |
| `raypick/bvh.py` | BVH 层次包围盒加速结构（构建、slab 求交、遍历排序） |
| `raypick/cli.py` | 命令行入口，读取 JSON、写出命中结果与统计 |

## 求交规则

`intersect` 使用 Möller–Trumbore 算法，返回 dict。命中时包含
`hit / tri / t / point / u / v / face`，未命中时包含
`hit / tri / reason`。三种特殊情况的处理规则如下：

1. **退化三角形（`reason="degenerate"`）**：三角形两条边共线
   （叉积的 L1 范数不大于 `EPS` 乘以两边 L1 范数之积）时，三角形面积
   为零、平面法向无定义，直接判定未命中，不参与后续计算。
2. **平行（`reason="parallel"`）**：射线方向与三角形平面法向接近垂直，
   即 `|det| ≤ EPS · ‖e1‖₁ · ‖d×e2‖₁` 时判定平行，未命中。阈值是
   **相对容差**，随射线长度与三角形尺寸缩放，因此极短射线、极小三角形
   不会被误判为平行。
3. **背面（不剔除，显式标注）**：三角形按**双面材质**处理，正面与背面
   命中都返回，不做背面剔除；命中结果用 `face` 字段标明朝向——
   `det > 0` 为 `"front"`，`det < 0` 为 `"back"`。选择双面策略是为了让
   拾取行为对三角形绕序不敏感；如需背面剔除，调用方依据 `face` 过滤即可。

其余两条确定性规则：

- **命中距离必须为正**：`t` 必须大于 `EPS · max(1, ‖d‖₁, ‖e2‖₁)`。
  射线起点落在三角形平面内时 `t == 0`，按未命中处理
  （`reason="behind"`），结果确定、可复现，不会出现零长度或负距离命中。
- **内外判定**：重心坐标必须满足 `u ≥ 0、v ≥ 0、u+v ≤ 1`
  （边界容差 `EPS`，含边界命中），否则 `reason="outside"`。

## 批量拾取与顺序稳定性

`pick_all` 在三角形集合上构建一棵 BVH（叶子容量 4，最长轴 + 质心中位数
分裂，稳定排序保证构建确定），每条射线沿显式栈遍历、近子树优先：

- 每条射线**只返回最近命中**；比较规则为先按 `t` 严格比较，
  **`t` 完全相等时取三角形编号更小者**。该规则在遍历收集后统一裁决，
  与 BVH 的遍历顺序、三角形输入顺序均无关，因此结果稳定。
- `hits` 与输入射线等长、同序；命中元素为
  `{"ray", "tri", "t", "point"}`，未命中元素为
  `{"ray", "tri": None, "t": None}`。

### 求交次数统计口径

`stats` 中：

- `intersection_tests`：**实际调用 `intersect` 的次数**。被 BVH 包围盒
  裁剪掉的子树、零方向射线的跳过，都不计入；
- `naive_tests`：全遍历基准次数 = 有效射线数（排除零方向）× 三角形数；
- `speedup = naive_tests / intersection_tests`；
- `tests_per_ray = intersection_tests / 有效射线数`。

## 边界情况

| 情况 | 确定结果 |
| --- | --- |
| 空场景（无三角形） | 所有射线未命中，求交次数为 0，`speedup` 为 0.0 |
| 空射线批次 | `hits` 为空列表，各项统计为 0 |
| 零方向射线 `(0,0,0)` | 直接记未命中，不构建遍历、不产生任何求交次数，计入 `zero_direction_rays` |
| 极短射线 | 方向不归一化，平行/正距离判定全部使用相对容差；命中距离按比例放大而交点不变 |
| 起点在三角形内 | `t == 0`，按 `behind` 未命中处理，两次调用结果完全一致 |

## 输出可复现性

BVH 构建（稳定排序 + 确定性分裂）与遍历（显式栈 + 近子树优先）都是
确定性的，浮点运算顺序固定。同一批射线连续调用两次 `pick_all`，
输出（含交点浮点值与统计数字）逐字节一致，测试中有断言覆盖。

## 实测数据

### 数据集 `data/rays.json`（2 条射线 / 1 个三角形）

运行 `python -m raypick.cli data/rays.json --out hits.json`：

- 命中率：**0.5000**（1 / 2，第二条射线落在三角形外）
- 平均求交次数：**0.50 次/射线**（实际 1 次，全遍历基准 2 次，
  另一条射线被包围盒直接裁剪，加速比 2.00x）
- 最近命中距离分布：桶 `1e0` 共 1 个；min = max = mean = **5.0**
- 退化三角形数：**0**

### 合成大场景（32×32 网格，1024 个三角形 / 600 条射线）

小数据集没有加速空间，另用确定性伪随机生成的网格场景验证加速效果
（脚本见测试中的 `_grid_scene` 同构构造）：

- 命中率：**0.8333**（500 / 600）
- 平均求交次数：**4.0 次/射线**（实际 2,400 次 vs 全遍历 614,400 次，
  **加速比 256x**）
- 最近命中距离分布：桶 `1e0` 共 500 个；min = max = mean = **3.0**
- 退化三角形数：**0**
- 两次运行结果完全一致：**是**
